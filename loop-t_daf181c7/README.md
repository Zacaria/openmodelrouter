# Boucle locale expérimentale

Cette tranche réutilise `pilot-t_f21a25b3/safe_router.py` : `Session.run(request)` reçoit uniquement `{"messages": [{"role": "user|assistant|system", "content": "…"}]}`. Elle accepte un historique strictement prolongé, fige la première route par objet Session et appelle le décideur uniquement avec le premier prompt utilisateur. Le comparateur doit créer un objet par conversation et conserver cet objet entre les tours ; aucune identité de session OMP n'est supposée fiable. L'interface de décision est une fonction `decide(prompt) -> nom_de_route`, ou une commande locale JSON en CLI. La configuration des routes est celle de safe_router (`command`, `model`, `effort`, `timeout_seconds`, `fallback` optionnel). Les commandes sont de confiance, non isolées ; aucun accès privé ni réseau ne leur est autorisé par cette tranche.

Les outils, sous-agents, champs supplémentaires et contexte non fourni sont refusés, sans appel du décideur ni du générateur. Un plafond de 100 000 octets s'applique à l'enveloppe. La réponse indique route, modèle et effort demandés, temps total, raison du repli et résultat du générateur ; effort appliqué et consommation sont ceux rapportés par le générateur, ou inconnus. Le repli n'est permis qu'en cas d'échec du décideur et seulement s'il est explicitement configuré ; une panne du générateur termine le tour sans repli. Les erreurs ne sont pas journalisées avec du contenu. Aucun mécanisme ne rend ces commandes sûres pour des données privées : pas de sandbox ni d'authentification.

CLI : `python3 loop.py --config CONFIG < request.json`. La CLI traite un seul tour par processus ; l'API Session est nécessaire aux conversations. La passerelle OMP existante `integrated-t_dab1958b/gateway.py` ne consomme pas encore cette API : son essai OMP historique ne démontre donc pas le figement. L'intégration aval doit raccorder explicitement cette interface et vérifier les identités, permissions et capacités OMP ; elle ne doit pas supposer que SSE est incrémental ou que l'effort est appliqué. Aucun benchmark, économie, compatibilité outil ou usage de production n'est revendiqué.

Tests : `python3 -m unittest -v` depuis ce dossier. Aucun paquet additionnel requis pour les tests synthétiques.
