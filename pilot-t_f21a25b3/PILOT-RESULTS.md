# Pilote local du 26 octobre 2026

Un cas synthétique, une répétition, trois bras exécutés le 26 octobre : 3 reçus, 0 échec ; génération intégralement simulée et oracle artificiel `ok`. Le bras s1d1 a exécuté le wrapper officiel sur les poids locaux ONNX tiny révision `dac13b5c0356864ea4501fa151d74dcd8b3ea22a`, avec le premier message. Le bras configurable utilisait un décideur local simulé ; le défaut utilisait directement le générateur simulé. Ce test ne compare pas des modèles génératifs réels. Les compteurs 10 et 2, tarifs et coûts dans les reçus sont inventés par le générateur synthétique et ne mesurent aucune facture ni le coût de classification. L'étiquette globale `simulated` masque le composant s1d1 réel : elle ne doit pas être utilisée comme preuve de provenance par composant. Les latences comprennent les lancements de processus et l'initialisation modèle.

Exécution : `python3 benchmark.py pilot-local-benchmark.json benchmark-example-cases.json pilot-local-results.jsonl`, puis `python3 compare.py pilot-local-results.jsonl`. Les configurations locales comportent des chemins propres à cette machine et ne sont pas distribuées comme configuration portable. Le fichier de reçus original est conservé avec ce document. `python3 -m unittest -v` : 11 tests réussis avant préservation.

Manques : OMP et un générateur local ne sont pas disponibles dans le PATH observé ; aucune intégration hôte, effort effectif, permission OS, fallback, jeu de familles complet, usage réel ou mesure d'économie n'est vérifié. Les commandes des routes sont du code de confiance ayant les droits de l'utilisateur ; l'environnement vide n'est pas une sandbox. Le générateur reçoit la requête entière. Ne pas utiliser ce prototype pour une session ou des données privées. Un adaptateur hôte, un générateur local et des garde-fous vérifiés sont nécessaires avant la livraison. Aucun téléchargement de modèle génératif, appel distant, coût ou transmission de session réelle n'a été effectué.
