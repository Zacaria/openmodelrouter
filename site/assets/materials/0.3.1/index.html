Sources du moteur macOS ARM64 · 0.3.1

Le complément 0.3.1 s’applique aux sources de reconstruction du moteur fournies avec le kit 0.3.0. Le complément ne modifie pas le pont Bun ni l’extension native du kit de base.

  1. Télécharger le kit de base, ses dépendances et ses licences.
  2. Télécharger le complément 0.3.1.
  3. Extraire le kit de base, puis exécuter patch -p1 < rebuild.patch depuis le dossier contenant pi-ai-distribution/.
  4. Suivre les instructions de pi-ai-distribution/rebuild/REBUILD-MAC-T_ABD8669B.md et vérifier les fichiers avec pi-ai-distribution/manifest.json.
