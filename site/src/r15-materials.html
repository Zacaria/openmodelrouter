Sources du moteur macOS ARM64 · 0.3.2

  1. Télécharger le kit de base 0.3.0, ses dépendances et ses licences.

macOS ARM64 engine sources · 0.3.2

Download the 0.3.0 base kit and the 0.3.2 update above. Extract the update from the directory containing pi-ai-distribution/; it replaces files of the same name. SOURCE-MANIFEST.json lists the updated files and their checksums. SOURCE-REFERENCE.json lists the engine’s source materials, including the WebKit archive offered with the base kit.

The base kit’s bin/omr-pi is from 0.3.0, not 0.3.2. Its original manifest does not describe the files replaced by this update.
