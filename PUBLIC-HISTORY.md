# Public source snapshot

This repository starts with a signed, metadata-redacted source snapshot derived
from the accepted R15 code and its subsequent distribution preparation. It does
not contain the original private Git history. Machine paths and real LAN hosts
were replaced with illustrative values; local probes require the operator's own
configuration. Historical outputs and hashes describe the private originals, not
the redacted files. Third-party notices and legitimate synthetic fixtures remain.

The root signature attests this derived snapshot, not the original commits or a
new product build. This snapshot is not evidence that the released DMG was built
from these exact bytes. The original objects and the mapping are retained privately.
